## 미션 1 · 로컬에서 진짜 MySQL에 붙여서 테스트 통과시키기

**배우는 것:** 이 앱은 DB 없이는 테스트가 안 된다는 것을 직접 겪기, CI에 올리기 전에 로컬로 먼저 검증

### ① 테스트용 MySQL 컨테이너 띄우기

```bash
docker run -d --name notes-mysql-local \
  -e MYSQL_ROOT_PASSWORD=testpassword \
  -e MYSQL_DATABASE=notesdb \
  -p 3306:3306 \
  mysql:8

# 완전히 뜰 때까지 대기 (몇 초 걸림)
for i in $(seq 1 30); do
  docker exec notes-mysql-local mysqladmin ping -h localhost -ptestpassword 2>/dev/null | grep -q "mysqld is alive" && echo "준비됨" && break
  sleep 2
done
```

### ② 의존성 설치 + 테스트 실행

```bash
cd 07-real-pipeline/app
npm install

DB_HOST=127.0.0.1 DB_USER=root DB_PASSWORD=testpassword DB_NAME=notesdb npm test
```

**확인 포인트**
- [ ] `✅ MySQL 연결 성공!` 로그
- [ ] `Tests: 2 passed, 2 total`

<details><summary>힌트: DB_HOST를 안 주고 그냥 npm test만 돌리면?</summary>

`db.js`가 `process.env.DB_HOST`를 그대로 쓰기 때문에 값이 없으면 연결 자체가 안 되고, `connectWithRetry()`가
계속 재시도하다가 결국 타임아웃난다. 실제로 한번 `DB_HOST=` 없이 `npm test`를 돌려서 어떻게 실패하는지
봐도 좋다 (Ctrl+C로 중단 가능).
</details>


## 미션 2 · GitHub Actions에 테스트 job 연결 (Service Container)

**배우는 것:** `jobs.<job>.services`, `--health-cmd`, 러너에선 `127.0.0.1`로 접근한다는 것

### ① 파일 작성

```bash
mkdir -p .github/workflows
cat > .github/workflows/07-real-pipeline.yml <<'EOF'
name: 07 - Real Pipeline

on:
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  test:
    runs-on: ubuntu-latest
    services:
      mysql:
        image: mysql:8
        env:
          MYSQL_ROOT_PASSWORD: testpassword
          MYSQL_DATABASE: notesdb
        ports:
          - 3306:3306
        options: >-
          --health-cmd="mysqladmin ping -h localhost -ptestpassword"
          --health-interval=5s
          --health-timeout=5s
          --health-retries=10
    defaults:
      run:
        working-directory: 07-real-pipeline/app
    steps:
      - name: 코드 체크아웃
        uses: actions/checkout@v4

      - name: Node.js 설치
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
          cache-dependency-path: 07-real-pipeline/app/package-lock.json

      - name: 의존성 설치
        run: npm ci

      - name: 테스트 실행 (MySQL service container 연결)
        env:
          DB_HOST: 127.0.0.1
          DB_USER: root
          DB_PASSWORD: testpassword
          DB_NAME: notesdb
        run: npm test
EOF
```

### ② 커밋 & push


## 미션 3 · Docker 빌드 + Docker Hub push job 추가

**배우는 것:** `needs:`로 job 연결, 5회차에서 등록한 Secrets/Variables 재사용

> 5회차에서 등록한 `DOCKERHUB_USERNAME`(Variable), `DOCKERHUB_TOKEN`(Secret)을 그대로 씁니다.
> `gh variable list` / `gh secret list`로 아직 남아있는지 확인만 하고 넘어가면 됩니다.

### ① 파일 작성 (덮어쓰기) — `docker-push` job 추가

```bash
cat > .github/workflows/07-real-pipeline.yml <<'EOF'
name: 07 - Real Pipeline

on:
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  test:
    runs-on: ubuntu-latest
    services:
      mysql:
        image: mysql:8
        env:
          MYSQL_ROOT_PASSWORD: testpassword
          MYSQL_DATABASE: notesdb
        ports:
          - 3306:3306
        options: >-
          --health-cmd="mysqladmin ping -h localhost -ptestpassword"
          --health-interval=5s
          --health-timeout=5s
          --health-retries=10
    defaults:
      run:
        working-directory: 07-real-pipeline/app
    steps:
      - name: 코드 체크아웃
        uses: actions/checkout@v4

      - name: Node.js 설치
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
          cache-dependency-path: 07-real-pipeline/app/package-lock.json

      - name: 의존성 설치
        run: npm ci

      - name: 테스트 실행 (MySQL service container 연결)
        env:
          DB_HOST: 127.0.0.1
          DB_USER: root
          DB_PASSWORD: testpassword
          DB_NAME: notesdb
        run: npm test

  docker-push:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - name: 코드 체크아웃
        uses: actions/checkout@v4

      - name: QEMU 설정 (멀티 아키텍처 빌드용)
        uses: docker/setup-qemu-action@v3

      - name: Buildx 준비
        uses: docker/setup-buildx-action@v3

      - name: Docker Hub 로그인
        uses: docker/login-action@v3
        with:
          username: ${{ vars.DOCKERHUB_USERNAME }}
          password: ${{ secrets.DOCKERHUB_TOKEN }}

      - name: 이미지 빌드 + push
        uses: docker/build-push-action@v6
        with:
          context: ./07-real-pipeline/app
          platforms: linux/amd64,linux/arm64
          push: true
          tags: |
            docker.io/${{ vars.DOCKERHUB_USERNAME }}/cicd-study-notes:latest
            docker.io/${{ vars.DOCKERHUB_USERNAME }}/cicd-study-notes:${{ github.sha }}
          cache-from: type=gha
          cache-to: type=gha,mode=max
EOF
```
